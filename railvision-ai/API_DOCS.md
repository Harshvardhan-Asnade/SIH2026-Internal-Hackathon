# RailVision AI — API Documentation

## Overview
The RailVision AI backend is a FastAPI-powered REST API that handles video uploads, runs computer vision inference, and serves a natural language AI Assistant interface.

## Endpoints

### `POST /upload`
Uploads a video file for processing.

**Request Body (multipart/form-data)**
- `file`: The video file (MP4, AVI, MOV, MKV). Max 500MB.

**Response (JSON)**
- `status` (string): "success"
- `message` (string): Human-readable success message
- `video_id` (string): A unique 12-character hex ID used to trigger processing
- `filename` (string): The sanitized filename stored on disk

---

### `POST /process`
Triggers the full AI inference pipeline on an uploaded video.

**Request Body (JSON)**
- `video_id` (string): The ID returned from `/upload`.
- `confidence` (float): The detection confidence threshold (0.0 to 1.0).

**Response (JSON)**
Returns a massive `ProcessingResult` object containing:
- `fps` (float): Processing speed
- `processing_time` (float): Total processing time in seconds
- `detections` (list): Array of all tracked bounding boxes
- `crowd_analysis` (object): Statistics on crowd density and heatmaps
- `crime_detection` (object): Arrays of crime events (intrusions, fights, loitering)
- `worker_monitoring` (object): Statistics on staff PPE compliance
- `alerts` (list): Critical system alerts
- `ai_master_report` (string): An intelligence report generated by Qwen 3

---

### `GET /outputs/{video_id}/{filename}`
Serves processed videos and generated heatmaps.

---

### `POST /query`
Sends a natural language question to the Qwen 3 AI Master about the most recently processed video.

**Request Body (JSON)**
- `query` (string): The user's question (e.g. "Were there any fights in the station?").

**Response (JSON)**
- `status` (string): "success"
- `answer` (string): The LLM's response
- `confidence` (string): "High", "Medium", or "Low"
