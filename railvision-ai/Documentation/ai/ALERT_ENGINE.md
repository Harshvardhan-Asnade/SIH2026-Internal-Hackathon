# Alert Engine Architecture

**Status**: [IMPLEMENTED]
**Location**: `app/ai/alerts/`

## 1. Role
The Alert Engine listens to event outputs generated by individual AI modules (`CrowdAnalysisModule`, `CrimeDetectionModule`, `WorkerMonitoringModule`) and formats them into standardized, actionable event objects.

## 2. Event Structure
Every alert emitted conforms to the `AlertEvent` Pydantic schema:

```json
{
  "alert_id": "alt_89f3a12",
  "timestamp": "2026-08-09T14:30:15Z",
  "frame_idx": 450,
  "source_module": "crime_detection",
  "alert_type": "SUSPICIOUS_LOITERING",
  "severity": "HIGH",
  "description": "Person (Track #14) stationary in Zone 2 for 45s",
  "metadata": {
    "track_id": 14,
    "duration_seconds": 45,
    "zone": "Zone 2 - Platform 1"
  }
}
```

## 3. Pipeline Destination
All alerts created during video processing are serialized into `outputs/{video_id}/report/alerts.json` and merged chronologically into `timeline.json`.
